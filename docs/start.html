Primeros pasos con PyPhonOS

Getting started with PyPhonOS

Estos pasos te llevan de un entorno limpio a una ventana con su primer contenido en unos minutos.

These steps take you from a clean environment to a window with your first content in minutes.

1 · Instalación

1 · Installation

La distribución se llama pyphonos y el paquete de importación pyphon.

The distribution is pyphonos; the import package is pyphon.

# Python >= 3.9
pip install pyphonos

PySDL2 se instala de forma automática. En Windows puedes añadir el extra binary para obtener las bibliotecas nativas SDL2, SDL2_ttf y SDL2_image sin instalarlas a mano:

PySDL2 installs automatically. On Windows, add the binary extra to ship the SDL2, SDL2_ttf and SDL2_image native libraries without manual setup.

pip install "pyphonos[binary]"

2 · Tu primera ventana

2 · Your first window

Crea un MobileApp, pide una Screen raíz y ejecuta el bucle con run().

from pyphon.core.app import MobileApp

app = MobileApp(titulo="Hola", ancho=360, alto=640)
# 360x640 es la resolución lógica; la GPU escala a pantalla completa.
app.run()

Solo con esto ya se abre una ventana resizable y con sondeo de eventos a 60 FPS. Cierra con Esc o la X.

3 · Estructura de una app

3 · App structure

El patrón es: construye una Screen, añade widgets, y cuando la app navegue la mostrará. Cada pantalla implementa build().

from pyphon.core.app import MobileApp
from pyphon.core.navigator import Screen
from pyphon.widgets import (
    Button, Label, VerticalLayout, StatusBar)

class Home(Screen):
    def build(self):
        root = VerticalLayout(width=360, height=640, spacing=14)
        root.add_widget(StatusBar(width=360))
        root.add_widget(Label(text="Bienvenido", size=34))
        boton = Button(text="Pulsa",
                        on_click=lambda: print("ok"))
        root.add_widget(boton)
        self.add(root)

def main():
    app = MobileApp(titulo="Demo")
    app.load_bundled_resources()  # locales y tema del paquete
    app.push_screen(Home())       # lo muestra con animación
    app.run()

main()

4 · Recursos empaquetados

4 · Bundled assets

El distributable incluye tipografías Roboto, traducciones es.json/en.json y un theme.json. La llamada load_bundled_resources() los registra. Para acceso de bajo nivel:

from pyphon._res import FONTS_DIR, LOCALES_DIR, THEME_JSON

Siempre que dibujes texto, el lienzo los buscará solo si colocas la fuente en assets/fonts, algo que ya ocurre con Roboto-Regular y Roboto-Medium tras instalar.
