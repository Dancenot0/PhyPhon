Motor de la aplicaciónApplication engine

El módulo pyphon.core coordina la ventana, el bucle de dibujo y el sistema de navegación.The pyphon.core module coordinates the window, the drawing loop and the navigation system.

MobileApp

Clase central. Crea la ventana nativa (SDL2), un Canvas, el gestor de temas, animación, navegación e i18n, y mantiene el ciclo procesar/renderse.The central class. It creates the native window (SDL2), a Canvas, plus theme, animation, navigation and i18n managers, and runs the process/render loop.

Screen y su ciclo de vida

Una Screen representa una vista a pantalla completa con widgets y enlaces de color. Define build() para montar contenido; los demás son enlaces opcionales, parecidos a los ciclos de actividades móviles.A Screen is a full-screen view holding widgets. Override build() to assemble it; the rest are optional lifecycle hooks similar to mobile activity callbacks.

MétodoCuándo se llamaCalled when
build()Se monta el contenido (una vez).Content is assembled (once).
on_enter()Pantalla recién apilada.Screen was just pushed.
on_leave()Va a quedar tapada o a salir de pila.It is about to be covered or popped.
on_resume()Volvió a estar visible al desapilar.Became visible again after a pop.
class Perfil(Screen):
    def build(self):
        self.estado = Label(text="Perfil")
        self.add(self.estado)
    def on_enter(self):
        self.estado.text = "Cargando..."   # refresco al llegar
    def on_leave(self): pass
    def on_resume(self): pass

Navigator: pila de pantallas

Navigator gestiona una pila, dibuja la pantalla superior y traduce gestos (tocar, Esc, retroceso) en funciones de navegación. El uso normal es a través de MobileApp, pero puedes instanciarlo para prototipar sin ventana.Navigator manages a stack, draws the top screen and maps gestures (tap, Escape, back) to navigation. Normally you reach it through MobileApp, but it can be built alone for headless prototyping.

MétodoEfectoEffect
push(screen)Añade con transición animada.Push with an animated transition.
pop()Quita la superior.Pop the top screen.
replace(screen)Sustituye la actual.Swap the current screen.
pop_to_root()Vacía hasta la raíz.Pop down to the root.
current_screenPantalla visible.Visible screen.
can_go_backPermite retroceder.Whether going back is possible.

Señales y eventos propios

Cada Widget trae un EventHandler donde conectas callbacks (por ejemplo events.on_click.connect(...)). Para llamadas desacopladas existe Signal en pyphon.events.Every Widget exposes an EventHandler where you connect callbacks (for example events.on_click.connect(...)). For decoupled calls there is Signal in pyphon.events.

from pyphon.events.signals import Signal

class Store:
    def __init__(self):
        self.comprado = Signal()

tienda = Store()
tienda.comprado.connect(carrito.anadir)
tienda.comprado.emit(producto=id_producto)  # invoca a los conectados

Inspector en ejecución

Pulsa F12 mientras corre la app para activar WidgetInspector: dibuja bordes, identificadores y recorre los widgets bajo el cursor. Útil para depurar jerarquías.While running, press F12 to enable WidgetInspector: it draws borders, identifies widgets and inspects what is under the cursor — handy for debugging hierarchies.

Recuerda: cierra los recursos con la ventana; run() usa finally para limpiar la pantalla nativa.Remember: resources are closed with the window; run() uses finally to clean up the native window.
