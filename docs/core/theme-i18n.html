Tema, color y traduccionesTheming, colour and translations

Basado en Material Design 3. Separa el color en dos capas: una paleta estática (renderer/colors.py) y un gestor dinámico (core/theme.py) que remapea tokens según modo y acento.Built on Material Design 3 ideas. Colour is split in two layers: a static palette (renderer/colors.py) and a dynamic manager (core/theme.py) that remaps tokens by mode and accent.

La clase Color

Valor RGBA con conversión CSS y derivados armónicos.

MétodoFunciónPurpose
Color(r,g,b,a=255)Construir un color normalizado.Build a normalized colour.
to_hex() / from_hex()Conversión a/desde #rrggbb.Convert to/from a #rrggbb string.
brighten(n) / darken(n)Tono derivado para estados.Derived tone for states.
from pyphon.renderer.colors import Color
c = Color(26, 35, 126)
print(c.to_hex())            # "#1A237e"
claro = c.brighten(0.15)     # para estados "pressed"

Palette

Conjunto global de colores semánticos del tema: PRIMARY, BACKGROUND, SURFACE, OUTLINE, grises y más. Es lo que uses en los widgets por defecto.Global set of semantic colours: PRIMARY, BACKGROUND, SURFACE, OUTLINE, greys and more, used as defaults across widgets.

widget.background_color = Palette.SURFACE
texto.color = Palette.PRIMARY

ThemeManager

Expone tokens derivados del acento y del modo (propiedades como primary, background, surface, card, text_primary, outline, scrim...). Se obtiene de app.theme.Exposes tokens derived from the accent and mode (primary, background, surface, card, text_primary, outline, scrim and so on). Access it via app.theme.

manager = app.theme
manager.set_dark_mode(True)
manager.toggle_dark_mode()          # alterna claro/oscuro
manager.set_accent("teal")        # o set_custom_accent(Color)
app.add_listener(mi_callback)       # notifica cambios de tokens

Escucha los cambios del tema conectando oyentes a add_listener/remove_listener.

manager.add_listener(lambda: print("tema actualizado"))

Tema desde fichero y hot-reload

Puedes persistir o consultar un tema guardado en JSON; el hot-reload recalcula al modificar el archivo sin reiniciar la app. El paquete incluye un theme.json de ejemplo que load_bundled_resources() aplica si existe.You can persist a theme as JSON; hot-reload recomputes when the file changes without a restart. The package ships a sample theme.json that load_bundled_resources() applies when present.

manager.enable_hot_reload("theme.json", check_interval=1.0)
manager.save_theme_json("theme.json")

Internacionalización (i18n)

Gestiona claves planas "a.b.c" con fusión en profundidad, notifica cambios de idioma y permite cargar carpetas de JSON (como las locales/es.json empaquetadas). Hay un módulo t(...) helper para acceder.Handles dot-keys like "a.b.c" with deep merge, notifies on language changes and can load directories of JSON files (like the bundled locales/es.json). A t(...) helper is provided.

from pyphon.core.i18n import I18nManager, t
m = app.i18n                     # ya creado por MobileApp
m.add_translations("en", {"inicio.saludo": "Hi"})
m.set_language("en")
print(t("inicio.saludo"))     # "Hi"  — resuelve la clave
print(m.current_language)
El ejemplo examples/quickstart.py usa load_bundled_resources() para cargar locales/es.json y locales/en.json que viajan dentro del paquete.The bundled examples/quickstart.py demo uses load_bundled_resources() to load the locales/es.json and locales/en.json shipped in the package.
