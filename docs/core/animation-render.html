Animación y renderizadoAnimation and rendering

El subpaquete core aporta un motor de animación por propiedades; renderer aporta el lienzo SDL2 y utilidades de dibujo como sombras, cristal y contraste.The core subpackage provides a property animation engine; renderer provides the SDL2 canvas plus drawing utilities such as shadows, glass and contrast.

Curvas de easingEasing curves

El catálogo Easing.FUNCTIONS devuelve funciones que mapean el progreso t∈[0,1] a un valor suavizado. Puedes usar Easing.get(nombre) o un nombre de cadena en cualquier animación.The Easing.FUNCTIONS catalog maps progress t∈[0,1] to a smoothed value. Use Easing.get(name) or any key string.

NombreComportamientoBehaviour
linearDirecto, sin aceleración.
ease_in / ease_out / ease_in_outSuaves para entradas/salidas.Soft at start, end or both.
bounce, elastic, spring, overshoot, decelerate, anticipateEfectos "físicos" para feedback táctil.Physics-like effects for tactile feedback.

AnimationManager

Implementa tweens del valor de una propiedad del widget a otro con duración, delay y al terminar un callback.Implements property tweens to a target value with duration, delay and an on-complete callback.

m = app.anim                    # AnimationManager de la app
m.tween(boton, "width", 280, duration=0.4, easing="ease_out",
         on_complete=lambda: print("listo"))
m.fade_in(carta)                   # opacidad 0→1
m.fade_out(carta)
m.slide_in(panel)                  # desde fuera del área
m.slide_out(panel)
m.scale(tarjeta, 1.2)              # hacia adelante
m.pulse(boton, scale_factor=1.05)  # micro-feedback "haptic"
m.stagger(secuencia, duration=0.3) # anima en lote encadenado
m.cancel(objetivo)                 # detiene tweens activos

Tip: los widgets ya exponen un atajo widget.animate(duration, easing, opacity=..., y=..., ...) que delega aquí.Tip: widgets expose a shortcut widget.animate(duration, easing, opacity=..., y=..., ...) that delegates here.

boton.animate(y=200, opacity=0, duration=0.5, easing="bounce")

Primitivas de bajo nivelLow-level primitives

Si extiendes un widget puedes dibujar tu propio draw(canvas). El Canvas aporta rectas, círculos, esquinas redondeadas, sombras, texto y sprites.When writing a custom widget you implement draw(canvas). The Canvas offers rects, circles, rounded corners, shadows, text and sprites.

def draw(self, canvas):
    canvas.draw_rounded_rect(self.x, self.y, self.width,
                             self.height, 12,
                             self.background_color.to_hex())
    canvas.draw_text(self.texto, self.x+10, self.y+8,
                     "#1a1a1a", size=18)
