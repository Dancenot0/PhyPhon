Conjunto centrado en datos y contexto del dispositivo, además de componentes para mostrar listados y contenido visual.A data- and device-oriented set, plus components for lists and visual content.

Acceso a archivos

ClasePara qué sirvePurpose
FilePickerElegir un archivo del entorno.Pick a file from the environment.
DirectoryPickerSeleccionar una carpeta.Select a folder.
FileExplorerNavegar por un sistema de ficheros.Browse a filesystem.
from pyphon.widgets import FilePicker, FileExplorer, DirectoryPicker

fp = FilePicker(path=".")        # resuelve rutas con separador según OS
carpetas = DirectoryPicker()       # para elegir destino de exportación
arbol = FileExplorer()             # lista del último directorio

Estos widgets inspeccionan el disco local vía os/pathlib; comprueban os.path antes de presentar cada entrada. Es un acceso directo al sistema, sin permisos nativos extra.These widgets inspect the local drive through os/pathlib and stat each entry before listing it. Direct filesystem access, no extra native permissions.

Tarjetas y imagen

ClasePara qué sirvePurpose
CardSuperficie elevada con esquinas y sombra.Elevated, rounded surface.
ImageCarga PNG/JPG de ruta local en el lienzo.Loads a local PNG/JPG into the canvas.
ImageView / GalleryViewVista de una imagen o galería.Single image or gallery view.
from pyphon.widgets import Card, Image, ImageView

targeta = Card(width=300, height=180)
imagen = Image(src="foto.png")      # png/jpg; carga diferida sobre canvas
targeta.add_child(imagen)

Info del sistema

from pyphon.widgets import StorageInfo, BatteryIndicator, NetworkStatus

libre = StorageInfo()          # espacio de la unidad actual
bateria = BatteryIndicator()   # nivel de batería si el SO lo reporta
red = NetworkStatus()          # conectividad / estado WiFi

Conversación

from pyphon.widgets import ChatBubble, MessageView, NotificationCenter

burbuja = ChatBubble(message="Hola", is_me=True)
thread = MessageView()      thread.add_child(burbuja)
notif = NotificationCenter()   # cola de avisos del sistema

Vistas especializadas (vista previa)Specialized views (preview)

specialized.py y advanced.py agrupan scaffolds de engranes más ambiciosos —WebView, MapView, ChartView, CalendarView, editores, y vocabulario AR/VR/neumorfismo— que definen su contrato visual y dejan dibujos a un backend concreto. Si tu escena ya tiene un host (por ejemplo, un canvas Web o GL), estos proveen el punto de enganche y las propiedades esperadas.specialized.py and advanced.py group more ambitious engine scaffolds — WebView, MapView, ChartView, CalendarView, editors, and AR/VR/neumorphic vocabulary — which define their visual contract and delegate drawing to a concrete backend. If your scene already owns a host, they provide the hook points and expected properties.

Para listar qué campos espera cada visita, abre el widget en el intérprete:To see which fields each widget expects, inspect in a REPL:
from pyphon.widgets.specialized import CalendarView
print(CalendarView.__init__.__doc__)   # o inspecciona el __init__
