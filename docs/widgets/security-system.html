Seguridad, plataforma y utilidadesSecurity, platform and utilities

Este bloque agrupa los dos extremos de una app móvil: proteger lo sensible y modelar interacciones del dispositivo, además de accesibilidad y utilidades.This block groups the two ends of a mobile app: protecting sensitive flows and modelling device interactions, plus accessibility and utilities.

Autenticación y seguridad

ClasePara qué sirvePurpose

from pyphon.widgets.security import BiometricPrompt, SecureKeyboard, PasswordStrengthMeter

Bio = BiometricPrompt()            # dispara el prompt de la plataforma
Bio.on_success.connect(acceder)
Bio.on_error.connect(mostrar_error)

fuerte = PasswordStrengthMeter()   # actualiza al escribir el PIN
teclado = SecureKeyboard()          # para la caja del PIN

Estas no crean un widget por sí solas: decoran a un hijo o responden a gestos del EventHandler raíz, por eso se conectan sobre el contenedor real.

These don't render standalone: they decorate a hosted child or react to events on the root handler, so attach them to a real container when wiring.

Superficies experimentales (advanced)Experimental surfaces

advanced.py reúne ARView, VRView, Object3DView, NeumorphicWidget, GlassmorphismPanel y DynamicIsland. Son contratos de alto nivel cuya representación depende del backend de la escena (WGPU/OpenGL/WebGL), no del lienzo 2D por defecto.advanced.py collects ARView, VRView, Object3DView, NeumorphicWidget, GlassmorphismPanel and DynamicIsland. These are high-level contracts whose rendering depends on a scene backend (WGPU/OpenGL/WebGL), not the default 2D canvas.

Recomendado: empieza por Controles y formularios y Feedback, que funcionan sobre el renderer por defecto.Recommended: begin with Controls and forms and Feedback, which run on the default renderer.
