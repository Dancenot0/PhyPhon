PyPhonOS · interfaz en Python sobre SDL2

Interfaces con estética móvil, renderizadas por GPU.Mobile-style interfaces rendered on the GPU.

PyPhonOS es una librería con la que describes vistas, controles, temas y animaciones en Python puro. El marco se encarga de crear la ventana, repartir los eventos y dibujar cada fotograma a través de SDL2. Esta documentación describe cada bloque de funcionalidad, para qué sirve y muestra cómo usarlo.PyPhonOS lets you describe views, controls, themes and animations in plain Python. The framework owns the window, event routing and per-frame drawing on top of SDL2. This documentation explains what every block does and how to use it.

# demo.py — primera pantalla
from pyphon.core.app import MobileApp
from pyphon.core.navigator import Screen
from pyphon.widgets import Button, VerticalLayout
from pyphon.renderer.colors import Palette

class Home(Screen):
    def build(self):
        root = VerticalLayout(width=360, height=800,
                              spacing=16, padding=24)
        root.background_color = Palette.BACKGROUND
        root.add_widget(Button(text="Hola PyPhon"))
        self.add(root)

def main():
    app = MobileApp(titulo="Mi app", ancho=360, alto=800)
    app.load_bundled_resources()
    app.push_screen(Home())
    app.run()
